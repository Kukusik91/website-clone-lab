# Project instructions

- Keep this project minimal and follow the existing backend/frontend layout.
- Never commit secrets, `.env` files, local databases, virtual environments, or dependency directories.
- Install project Codex skills with `powershell -ExecutionPolicy Bypass -File scripts/install-skills.ps1` after cloning.
- For interface work, consult the `$impeccable` skill; for substantial repository work, use `$dev-agent-workflow`.
- Verify backend startup and frontend production build when changing their respective code.
